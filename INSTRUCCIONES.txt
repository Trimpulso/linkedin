PASO 1: Abrir .env y completar datos
────────────────────────────────────

LINKEDIN_EMAIL=job.llanos@gmail.com
LINKEDIN_PASSWORD=Tito#2008
GEMINI_API_KEY=            ← COMPLETA ESTO
GITHUB_TOKEN=              ← COMPLETA ESTO


PASO 2: Obtener Google Gemini API Key (1 minuto)
─────────────────────────────────────────────

1. Ve a: https://aistudio.google.com/app/apikey
2. Click en "Create API Key"
3. Click en "Create API key in new project"
4. Copia tu API Key
5. Pégala en .env


PASO 3: Obtener GitHub Token (2 minutos)
────────────────────────────────────

1. Ve a: https://github.com/settings/tokens
2. Click en "Generate new token"
3. Dale un nombre descriptivo
4. Selecciona estos permisos:
   ✓ repo (completo)
   ✓ workflow (opcional)
5. Click "Generate token"
6. Copia el token (solo aparece una vez)
7. Pégalo en .env


PASO 4: Ejecutar el sistema
─────────────────────────

En Windows:
  C:\github\linkedin> start.bat

En Linux/Mac:
  $ bash start.sh


PASO 5: Abrir el chatbot
───────────────────

1. El backend se ejecuta en http://localhost:5000
2. Abre en tu navegador: C:\github\linkedin\frontend\index.html
3. ¡Listo! Comienza a usar el chatbot


🎯 CÓMO USAR EL CHATBOT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 PUBLICAR
──────────
1. Click en botón "📝 Publicar"
2. Escribe tu mensaje (máx 3000 caracteres)
3. Opcionalmente adjunta una foto
4. Marca "Mejorar con IA" si quieres que lo revise Gemini
5. Click "🚀 Publicar"
6. ¡Listo! Aparecerá en tu LinkedIn

💡 GENERAR SUGERENCIA
─────────────────────
1. Click en botón "💡 Sugerir"
2. Describe el tema (Ej: "Mi experiencia con Python")
3. Elige tono (Profesional, Casual, Inspirador)
4. Click "Generar"
5. Recibirás una sugerencia completa
6. Puedes copiarla y editarla

📋 VER HISTORIAL
────────────────
1. Click en botón "📋 Historial"
2. Verás tus últimos 5 posts
3. Ver fecha, contenido y estado

💬 CHAT CON IA
──────────────
1. Escribe cualquier pregunta en el chat
2. La IA responde automáticamente
3. Puedes pedir ayuda para redactar posts

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEMA: "Connection refused"
SOLUCIÓN: 
  1. Verifica que el backend está ejecutándose (start.bat)
  2. Verifica que el puerto 5000 está disponible
  3. Intenta con: netstat -ano | findstr :5000

PROBLEMA: "API Key inválida"
SOLUCIÓN:
  1. Copia bien la API Key de Gemini
  2. Crea una nueva en https://aistudio.google.com/app/apikey
  3. Reinicia el backend

PROBLEMA: "No puedo conectar a LinkedIn"
SOLUCIÓN:
  1. Verifica email y contraseña en .env
  2. Verifica que 2FA no está habilitado
  3. Intenta cambiar contraseña

PROBLEMA: "Las fotos no se suben"
SOLUCIÓN:
  1. Verifica el GitHub Token
  2. Verifica los permisos en GitHub
  3. Intenta crear la carpeta /fotos en GitHub manualmente
